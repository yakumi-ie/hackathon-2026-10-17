# よりみち

「動画のつづきは、街で。」
現在地の近くで、ニコニコ動画に登場した景色や体験を見つけるハッカソン用プロトタイプ。
スマートフォンを中心に、近くの地点を地図で確認し、動画カードをスクロールして視聴と経路検索へ進める。

## 起動

Node.js 22.12 以上を使用する。

```sh
npm run deps
npm run dev
```

http://localhost:3000/ を開く。
Docker Sandbox 内で起動した場合、ホストのブラウザから開くにはポート転送が必要。
Mac 側のターミナルで次を実行する（今回のサンドボックス名は `dw-hackathon`）。

```sh
sbx ports dw-hackathon --publish 3000:3000
```

転送後は http://127.0.0.1:3000/ を開く。
ポート転送の設定は [sbx ports の公式ドキュメント](https://docs.docker.com/reference/cli/sbx/ports/) を参照。

初期表示は上野駅のデモ地点で、位置情報を許可しなくても試せる。
徒歩は半径 1 km、車は半径 10 km の直線距離で検索する。
上野・浅草・東京・横浜・鎌倉のデモ地点を選べる。

「現在地を使う」でブラウザの位置情報を取得する。
localhost 以外では HTTPS が必要なため、スマートフォンから LAN の HTTP アドレスで開いた場合はデモ地点を使う。

## データ

[共有された動画旅マップ](https://www.google.com/maps/d/viewer?mid=13Xyxidjdp-PCcwAl2zI76WBqUSOKkX95) の KML から、関東周辺の 349 本・882 地点を収録。
抽出範囲は東経 139〜141 度、北緯 35〜36.5 度で、関東全域を網羅するものではない。
同じ動画の複数地点は一つのカードに集約し、最寄りの地点の距離で並べる。

アプリ内の地図には、現在の検索範囲に入る地点だけを表示する。
背景地図は OpenStreetMap、表示は Leaflet を使用する。
ピンと動画カードは共通の番号で結び、同じ座標の複数動画は一つのピンにまとめる。
近接したピンは青い丸に集約し、選ぶと拡大する。
青い丸の数字は、まとめたピンの数を表す。
カードの「地図で見る」で地点へ移動し、ピンから対応するカードへ戻れる。
動画一覧は検索結果を全件表示し、サムネイルを遅延読み込みする。
地図上でもホイール操作でページをスクロールできる。

地点名は元データにないため「マップ掲載地点」と表示し、座標をそのまま経路検索に使う。
Google マップへ移動手段・出発地点・目的地点を渡す。
動画はニコニコ動画で開く。
サムネイルはニコニコの公開 `getthumbinfo` API を元に、大きいサイズ（`.L`）の画像 URL を静的データへ取り込む。
Google マップの画像には依存しない。
削除済みなどでサムネイルを取得できない動画は代替表示にする。

更新には Python 3 の標準ライブラリだけを使う。

```sh
python3 scripts/import-map.py
```

## ビルドと配信

```sh
npm run typecheck
npm run build
npm run preview
```

TanStack Start のプリレンダリングで生成した `dist/client` を静的配信できる。
ランタイムの API サーバーやデータベースは不要。

Alpine Linux のコンテナ用に Dockerfile と nginx の設定を用意している。
SSL 終端はインフラ側で行う。

```sh
docker build -t yorimichi .
docker run --rm -p 8080:8080 yorimichi
```

## 依存パッケージの待機期間

`pnpm-workspace.yaml` に `minimumReleaseAge: 10080`（1 週間）を設定している。
今回の環境では指定の pnpmInstall MCP がこのリポジトリにアクセスできないため、npm と package-lock.json を使用する。
`npm run deps` でも、実行時から 1 週間前の公開日時を上限にしてインストールする。
コンテナのビルドには確定済みの lockfile を使う。

実装計画は [PLAN.md](PLAN.md) を参照。

## 確認済みの動作

型チェック、本番ビルド、生成された静的ファイルの配信で動作を確認した。
Chrome のスマートフォン相当の画面幅とデスクトップ幅で、以下を確認している。

- 徒歩 / 車の検索範囲と、動画・経路へのリンク。
- 上野駅の徒歩圏で 11 本、車の範囲で 47 本の表示。
- 抽出した地点だけの地図、近接ピンの集約、ピンとカードの相互移動。
- デモ地点の切り替えと、検索結果全件の表示。
- 位置情報の取得成功、拒否、未収録地域の結果なし表示。
- 取得中にデモ地点へ切り替えた場合、後から届く位置情報で上書きされないこと。

位置情報の成功・拒否はブラウザの開発者機能で再現して確認した。
スマートフォン実機での測位と、Docker コンテナの起動は未確認。
Playwright でホストの開発サーバーに接続し、320〜1920 px の幅でカードの重なりがないことと、ニコニコのサムネイル・OpenStreetMap の実表示を確認した。
地図上のホイール操作、同じ地点の再選択、位置情報の取得中の地点変更、画像・背景地図の取得失敗も確認した。
依存パッケージの監査は脆弱性 0 件で、lockfile の全パッケージが公開から 1 週間以上経過していることを確認した。
